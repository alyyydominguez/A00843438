
# Configuración del entorno - Actividad 2.7

## Herramientas utilizadas
- Visual Studio Code
- Anaconda
- Python 3.12
- pandas 2.3.3
- matplotlib
- Jupyter

## Preparación
1. Descargar el repositorio de GitHub.
2. Abrir la carpeta del proyecto en VS Code.
3. Crear el entorno con:
   conda env create -f environment.yml
4. Activar el entorno con:
   conda activate ti2006b-workbench
5. Seleccionar este entorno como intérprete de Python y kernel de Jupyter en VS Code.

## Ejecución
- Ejecutar `python src/hello_ds.py` desde la carpeta principal.
- Abrir `notebooks/02_workbench_check.ipynb` y ejecutar las celdas.

## Resultado
Se comprobó que Python funciona localmente en VS Code. Se creó una tabla de ventas ficticias y se identificó que los tenis generaron los mayores ingresos.
